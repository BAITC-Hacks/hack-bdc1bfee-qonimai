Использовать только fixtures/audio/synthetic_ru_two_speakers.wav. Это вымышленная
запись, синтезированная локальными голосами Windows. Заранее открыть приложение
http://127.0.0.1:8501 и резерв evidence/synthetic_previous_run.docx.

Фактическая длительность зависит от нагрузки. Не обещать укладывание модели в таймер.
Для показа ровно на 3 минуты обработать запись заранее и прямо назвать результат
ранее выполненным запуском. На реальной защите не тратить всё время на загрузку весов.
