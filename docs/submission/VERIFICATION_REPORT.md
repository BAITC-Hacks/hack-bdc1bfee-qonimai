## Что проверяли тесты

Корректность JSON и ссылок на сегменты, типы и конечность чисел, сопоставление
участников, относительные даты и календарный контекст, причины уточнений,
версию снимка, историю ручных правок и отказ от поддельных модельных правок.
Для DOCX — сохранение текста, порядка, казахских букв, неизвестных полей,
источников и ручных исправлений, атомарную запись, сохранность прежнего файла
при ошибке и безопасные сообщения об отказе.

Это не оценка распознавания, качества языка, полноты извлечения поручений или
визуальной вёрстки документа. Эталонные ответы fixtures написаны заранее.

## Как повторить на Windows / PowerShell

Из корня репозитория, с уже установленным Python 3.12:

```powershell
python -m pip download --only-binary=:all: -r requirements-export.txt --dest wheels
python -m venv .venv-check
.\.venv-check\Scripts\python.exe -m pip install --no-index --find-links wheels -r requirements-export.txt
.\.venv-check\Scripts\python.exe -m unittest discover -s tests -v
.\.venv-check\Scripts\python.exe docs/submission/evidence/run_socket_guard.py
```

Последняя команда перезаписывает только отчёт
`docs/submission/evidence/socket-guard-result.json` результатом своего запуска.
Для сохранения исходного свидетельства выполняйте повтор в отдельной копии
репозитория. Создание venv и загрузку выполняйте в новом каталоге/окружении;
уже существующее чужое окружение не перезаписывайте.

Socket-скрипт перед discovery блокирует `connect`, `connect_ex`,
`create_connection` и `sendto`, проверяет действие всех четырёх блокировок,
обнуляет счётчик проверочных вызовов, затем запускает тесты. Фактических
попыток этих операций во время discovery и тестов было 0.
**Это ограниченная проверка Python-процесса**, а не отключение интернета на ОС.
Она не блокирует нативные библиотеки, другие процессы или любые возможные
обходные сетевые пути. Полная offline-приёмка с моделями остаётся открытой.

## Визуальный контроль и блокер

Координатор запустил локальный `render_docx.py` для STRESS, но получил:

```text
FileNotFoundError: LibreOffice soffice.exe was not found on PATH
```

Bundled LibreOffice в доступном runtime не найден. PDF/PNG не созданы;
визуального PASS нет. Контрольные DOCX остались промежуточными локальными
файлами проверки и не включены в пакет как визуально принятые документы.
Для закрытия пункта нужно сформировать USER_CLARIFIED_DUE и STRESS,
отрисовать в разрешённой среде и просмотреть все страницы; проверить
`Ә Ғ Қ Ң Ө Ұ Ү Һ І ә ғ қ ң ө ұ ү һ і`, длинную строку, переносы, поля поручений,
источники и пояснения ручных изменений. Число XML-абзацев не является
числом страниц.
