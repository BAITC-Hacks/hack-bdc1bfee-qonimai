# Чек-лист готовности

Основание — требования команды и контракт v1. Полный Google Docs ранее не был
доступен; нельзя утверждать, что он прочитан. Обязательность интеграций требует ответа организаторов.

| Требование | Фактический статус |
|---|---|
| Загрузка готовой записи | Реализована в Streamlit; WAV/MP3/M4A/OGG, до 50 МБ и 5 минут |
| Русская речь | Реальный локальный ASR проверен на 29-секундной синтетической записи; были ошибки имени и числа слова |
| Казахская / смешанная аудиоречь | Мультиязычный ASR подключён, качество на записях не проверено; критерий не закрыт |
| Разделение голосов | Реальный WeSpeaker + кластеризация: 6 из 6 реплик двух синтетических голосов распределены верно; число голосов вводит пользователь |
| Имя говорящего | Отдельное ручное подтверждение в UI; диаризация не устанавливает личность |
| Действие, исполнитель, срок | 3/3 верны на последнем синтетическом сквозном сценарии; другие формулировки нестабильны |
| Автор отдельно от исполнителя | Подтверждено на поручениях другому участнику и в тестах |
| Неизвестный и относительный срок | missing_due/null и «завтра» верны в контрольном сценарии; отдельный TOMORROW_YEAR на финальном промпте отклонён |
| Саммари, источники | Реализованы; сверены с 6 репликами контрольного сценария |
| Исправления пользователем | UI и история исходных значений; изменение версии требует новой проверки |
| DOCX и полный транскрипт | Реализованы, автоматические проверки и визуальная приёмка описаны в LIVE_VERIFICATION |
| Казахские символы DOCX | XML-проверки есть; визуальная проверка синтетического стресс-документа отдельно от качества языка |
| Локальные модели | Фактически загружены с диска; анализ обращается только к loopback, без внешних API |
| Первоначальная загрузка | Отдельный setup_models.py; публичные веса, pinned revisions, SHA-256, лицензии |
| Полный запуск при отключённом внешнем интернете | Не проверен на уровне отключённой ОС; не выдавать offline-флаги за такую проверку |
| Уведомление и согласие | Текст и обязательный флажок перед загрузкой в UI |
| Teams/Zoom/Meet, live, напоминания | Не реализованы, обязательность уточнить |
| README и версии | Подготовлены, requirements-lock.txt, инструкция Windows PowerShell |
| Чистое окружение | Итог проверки см. LIVE_VERIFICATION и evidence/clean-install.txt |
| Резерв показа | Сохранены исходный ASR, проверенный снимок, настоящий ответ модели и DOCX; помечены как предыдущий запуск |
| Форма сдачи | Текст готов; нижние поля, доступ жюри и подтверждение отправки проверяет команда |

## Критерии жюри

| Критерий | Баллы | Что предъявляем |
|---|---:|---|
| Работоспособность | 25 | Реальные локальные модели и один подтверждённый сквозной сценарий; языковые ограничения раскрыты |
| Техническая реализация | 25 | Контракт, строгая проверка JSON, источники, версии, ручные правки, локальность |
| README и воспроизводимость | 25 | Точные версии, получение весов, Windows-запуск, тесты, сохранённые результаты |
| Ценность | 15 | Поручение связано с исполнителем и исходной репликой, неизвестный срок не придумывается |
| Развитие | 10 | Языковая приёмка, более точная модель, длинные записи, интеграции после уточнения |

Это сопоставление доказательств с критериями, а не прогноз баллов.
