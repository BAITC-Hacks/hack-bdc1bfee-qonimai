# Пакет сдачи QonimAI

**Сдаваемый результат — работающий локальный прототип с ограничениями качества.**
Реализованы загрузка аудио, русскоязычный интерфейс Streamlit, распознавание Whisper,
разделение голосов, подтверждение имён, анализ локальной Qwen3, ручная проверка и DOCX.
Один русский синтетический сценарий прошёл все вычислительные стадии: два голоса,
три поручения, явный срок, «завтра» и неизвестный срок. Исправления транскрипта перед
анализом сохранены отдельно. Казахский, смешанная речь и устойчивость на разных
записях ещё не приняты; два отдельных текстовых случая на финальном промпте не прошли.

## Перед отправкой

1. Проверить последний SHA и наличие этих документов в main репозитория хакатона.
2. Заполнить форму из SUBMISSION_FORM. Репозиторий не менять и не делать публичным.
3. Прокрутить форму до конца: нижние поля и обязательные вложения на скриншоте не видны.
4. Проверить доступ жюри и отправить заявку до конца таймера. Сохранить подтверждение.
   Git push не равнозначен отправке заявки; агент форму не отправлял.
