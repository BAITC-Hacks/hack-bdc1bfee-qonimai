# Пакет сдачи QonimAI

**Вердикт: частичный технический прототип. Полный MVP не готов.**
Сдавать текущую работу можно только с честным указанием отсутствующих функций;
допуск частичного результата определяет хакатон. Документы не подтверждают,
что организаторы согласились принять неполный MVP.

Реализованы проверки данных/JSON и локальный DOCX из проверенного снимка.
Нет загрузки аудио, ASR, диаризации, модели анализа и Streamlit.
204 теста прошли, 2 намеренно пропущены. Тесты выполнены в новом окружении;
установка из локальных колёс работает. Демонстрация полностью синтетическая.

## Перед нажатием «Сдать»

1. Открыть репозиторий хакатона на GitHub, проверить наличие этой папки в main
   и последний коммит. Зафиксировать SHA командой `git rev-parse HEAD`.
2. Заполнить название, теги и описание из SUBMISSION_FORM, не заявляя
   отсутствующую автоматическую обработку аудио.
3. Прокрутить форму целиком: нижние поля на переданном скриншоте не видны.
   Добавить обязательные вложения/ссылки, если их просит платформа.
4. Проверить доступ организаторов к приватному репозиторию. Не делать его
   публичным и не менять выданную платформой ссылку.
5. Отправить форму до завершения таймера и сохранить подтверждение платформы.
   Git push и подготовка этих документов сами по себе не отправляют заявку.

В репозитории нет весов, аудио, реальных транскриптов или готового приложения.
Архив исходников, если используется как вложение, тоже не содержит эти функции.

## Разделение последних действий

| Участник | Задача | Статус | Препятствие | Следующее действие |
|---|---|---|---|---|
| 1 | Сверить форму, таймер, доступ к репозиторию и README | Требуется человек | Нижняя часть формы и доступ жюри не проверены | Заполнить поля, проверить подтверждение отправки |
| 2 | Подготовить объяснение поручения, неизвестного срока и ручной правки | Сценарий готов | Нет автоматического анализатора | Прочитать RU_EXPLICIT / USER_CLARIFIED_DUE и отрепетировать 1 минуту |
| 3 | Проверить экспорт и внешний вид всех страниц | Автотесты прошли, визуально не принято | В среде агента нет рендерера DOCX | Выполнить команды README в рабочем Python, открыть документы локально |
| Координатор ИИ | Сборка кода, регрессия, документы и отправка в Git | Проверки выполнены; результат push сообщается в чате | Полный MVP отсутствует | Передать итоговый SHA и ссылки; не объявлять заявку отправленной |

## Следующий этап продукта

Выбрать локальные модели после проверки всей доступной техники и условий
получения весов. Собрать ранний проход аудио → транскрипт → локальный анализ
→ UI → DOCX; испытать RU/KK/MIXED с двумя голосами, затем чистый запуск
с готовыми весами при отключённом внешнем интернете. Интеграции и напоминания
добавлять после уточнения обязательности и закрытия базовых функций.
