# Данные, локальность и ограничения

Модели Whisper, WeSpeaker и Qwen3 работают на данном компьютере. Анализатор
допускает только http://127.0.0.1 или IPv6 loopback, запрещает прокси и редиректы.
Streamlit слушает 127.0.0.1. setup_models.py — отдельный этап получения публичных
весов; приложение его не вызывает. Он не читает записи совещаний.

Для обработки выставлены HF_HUB_OFFLINE, TRANSFORMERS_OFFLINE, запрет телеметрии;
модели загружаются из явных локальных путей. Это меры локальности, а не свидетельство
полного теста с физически отключённой сетью. Публичное размещение приложения и
удалённый закрытый сервер в эту сборку не входят.

## Уведомление перед записью

«Совещание записывается и обрабатывается локальными ИИ-моделями для подготовки
протокола и поручений. Результат будет проверен человеком. Запись и транскрипт
не передаются во внешние облачные API. Уточните у организатора встречи порядок
участия, доступ к материалам и срок хранения».

В интерфейсе подтверждается уведомление участников и допустимость обработки.
Команда должна заранее согласовать фактические сроки хранения и права доступа.
Реальные материалы не передавать в рабочие ИИ-чаты, Git, журналы или скриншоты демо.
Анонимизированные реальные данные также остаются внутри разрешённого контура.

Аудио в UI обрабатывается через локальный временный файл; результат находится
в памяти сессии. Загруженные пользователем DOCX сохраняются выбранным браузером.
Закрытие вкладки не равно гарантированному стиранию RAM/диска. CLI-сценарий сохраняет
только штатный синтетический пример в runtime/smoke. Логи сервера не должны включать
запросы. Веса и приватные каталоги исключены из Git.

## Границы MVP

- Запись до 5 минут / 50 МБ; анализ до 80 сегментов и 8000 символов JSON. Длинные
  данные отклоняются явно, разбиение на части пока отсутствует.
- Число говорящих задаётся пользователем. Перебивания, похожие голоса и шум не приняты.
- ASR может ошибаться в именах. Подтверждение голосов и исправление текста обязательны.
- Qwen3 может пропускать/придумывать поручения и ошибаться на казахском. Валидатор
  отсеивает часть ошибок, но не доказывает истинность каждого утверждения.
- UI позволяет исправлять существующие поля. Добавление/удаление пропущенных задач
  отдельным редактором пока не реализовано; неполный результат нельзя считать принятым.
- Проверены русский TTS-сценарий и синтетические контракты. RU/KK/MIXED на живых
  записях и проверка казахского человеком остаются открытыми.
- Нет подключения к звонкам, live-потока, напоминаний, серверной многопользовательской
  авторизации и промышленной политики хранения.

Единственный аудиофайл в Git целиком синтезирован локальными голосами Windows;
имена и содержание вымышлены. Эталон не подставляется вместо ответа модели.
