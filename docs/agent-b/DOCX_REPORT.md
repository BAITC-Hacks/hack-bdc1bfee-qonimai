## Ограничения и вопросы для координатора/интерфейса

- Интерфейс должен передавать `reviewed_revision` только после просмотра текущего снимка. Изменение снимка требует новой проверки; функция не подтверждает просмотр сама.
- Успешный вызов заменяет выбранный существующий файл. Выбор имени, согласие на замену и создание папки — ответственность вызывающего интерфейса. Публичный результат имеет утверждённую оболочку ExportResult.
- У пользовательской даты сохраняются и отсутствовавший исходный срок, и исходное значение даты, и объяснение правки. Для task/summary/decision исправления видны отдельно от извлечённых сведений.
- Общий экспортёр принимает проверенный снимок без признака синтетичности в контракте. Обязательную маркировку учебных образцов добавляет CLI. Будущему тестовому режиму UI также нужна явная маркировка; контракт ради этого не менялся.
- Если ОС блокирует собственный временный файл, его очистка может не выполниться; старый целевой документ ради очистки не удаляется. Защита от конкурентной подмены файловой системы отдельным процессом не заявляется.
- Не проверены: визуальное отображение DOCX, другие ОС/редакторы Word, чистая установка зависимостей, полный запуск без интернета, интеграция с UI, модели и качество распознавания/анализа. Казахские примеры требуют проверки человеком; сохранение букв не подтверждает языковую корректность.
- Новые зависимости или изменение контракта не предлагаются. Следующее необходимое действие — закрыть визуальную приёмку в разрешённой среде; потом координатор может принимать ветку. Отдельные чаты автоматически контекст не получают.
